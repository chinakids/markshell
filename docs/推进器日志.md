## 一、项目现状（2026-09-23 建档）

- 定位（README）：Android SSH/SFTP Markdown 文件阅读器——远程目录浏览、Markdown 渲染（Markwon）、文本批注（黄色虚线下划线+抽屉）、代码语法高亮（Prism4j）、图片查看、CSV 阅读、SSH 连接管理（多配置/快速重连/网络切换恢复）。
- 技术：Java（Java 8 语法）、AGP 8.2.0、minSdk 24 / targetSdk 34、Gradle 8.2、无 Android Studio（命令行构建）。
- 规模：26 个 Java 类 / ≈5.1k 行；无自动化测试基线（CI 只有 assembleDebug 构建）。
- 代码分层：ui/（各 Activity）、ui/span、widget/、util/、adapter/、ssh/、model/。
- 仓库：chinakids/markshell（public），已有 README/License(MIT)/android.yml CI。
